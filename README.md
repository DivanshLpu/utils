# Utils

A personal collection of reusable code snippets, helper functions, scripts, and small utilities that I use across projects.

The purpose of this repository is to reduce development time by keeping commonly used solutions in one place instead of rewriting them for every new project.

## What You'll Find

* Reusable code snippets
* Helper functions
* Utility scripts
* API examples
* Configuration templates
* Development tools
* Automation scripts
* Small standalone projects

## Goals

* Speed up development
* Reduce repetitive coding
* Keep solutions organized
* Reuse tested code across multiple projects
* Maintain a growing collection of practical utilities

## Usage

Browse the repository, find the utility you need, and copy or adapt it for your project.

Most utilities are designed to be lightweight, self-contained, and easy to integrate.

## Philosophy

* Write once, reuse many times.
* Keep solutions simple and maintainable.
* Prefer practical code over unnecessary complexity.
* Continuously improve and expand the collection.

## Contributing

This repository is primarily maintained for personal use, but suggestions, improvements, and bug fixes are always welcome.
